Red Lobster

Navigation

The navigation of this website is very well organized. Everything can be found near the search bar.

Usability

This website is very easy to use. It makes the ordering process more efficient than ordering in person.

Typography and hierarchy

The website uses san-serif type and makes the website look clear and simple to the eye. In all, the hierarchy is original with the larger menu items viewable first and the smaller items next.

Overall style/look and feel

The website has a very efficient style and a simple feel to it. It also matches the theme of the restaurant to an extent.
